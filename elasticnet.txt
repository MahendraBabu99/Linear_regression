ElasticNet / ElasticNetCV (Elastic Net Regression with Cross-Validation)
Overview

Elastic Net is a linear regression model that combines L1 regularization (Lasso) and L2 regularization (Ridge). It is designed to overcome the limitations of Lasso when features are highly correlated, while still providing feature selection.

ElasticNetCV extends Elastic Net by using cross-validation to automatically select the best regularization strength (alpha) and mixing parameter (l1_ratio).

Why Elastic Net is Used

Handles correlated features better than Lasso

Performs feature selection (via L1 penalty)

Stabilizes coefficients (via L2 penalty)

Automatically tunes hyperparameters with cross-validation

How It Works

A grid of alpha values and l1_ratio values is defined.

For each combination:

The model is trained using k-fold cross-validation

Validation error is measured

The best (alpha, l1_ratio) pair is selected.

The final model is retrained on the full dataset.

Key Parameters

alphas: Candidate regularization strengths (must be ≥ 0)

l1_ratio: Mix of L1 and L2 penalties (0 to 1)

cv: Number of cross-validation folds

max_iter: Maximum optimization iterations

n_jobs: Number of CPU cores
